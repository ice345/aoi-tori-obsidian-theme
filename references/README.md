# Local reference images

Place the visual reference images for palette and atmosphere analysis in this directory.

Recommended names:

```text
01-primary-watercolor.jpg
02-sky-blue-poster.jpg
03-pink-blue-watercolor.jpg
04-summer-blue-photography.jpg
```

Rules:

- Keep a note of each image's source and copyright status.
- Do not include copyrighted images in public release archives.
- Do not use film screenshots, posters, logos, or character art as the Community Themes cover.
- Use the images for analysis only.
- Update `docs/visual-analysis.md` after adding or replacing references.
