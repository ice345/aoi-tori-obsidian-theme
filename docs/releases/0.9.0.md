# Aoi Tori 0.9.0 Release Candidate

Status: public testing candidate. This is not a final stable `1.0.0` release.

## Core visual identity

- Warm paper-white reading surfaces with cool mist-blue side panels.
- Deep violet-navy body text rather than pure black or all-blue text.
- Deep cobalt for links, current state, primary actions, and keyboard focus.
- Sparse sakura pink and gray-violet second-voice accents.
- A tiny gold-orange counterpoint reserved for nonessential decoration.
- Independent summer-night dark mode, not an inverted light theme.

## Completed interface coverage

- Workspace shell: editor area, sidebars, ribbon, status bar, tabs, active/inactive states, and
  pop-out inheritance.
- Editor content: Live Preview, Source, Reading, headings, links, lists, quotes, callouts,
  Properties, tables, code, math, highlights, and selections.
- Controls and overlays: buttons, inputs, textareas, dropdowns, toggles, menus, modals, tooltips,
  notices, and Settings controls.
- Core views: Search, File Explorer, Outline, Backlinks, Tags, Bases, Canvas, Graph, PDF, and common
  embeds through official variables and tested stable selectors.

## Style Settings

The optional Style Settings plugin exposes 48 bounded controls across palette, typography,
workspace, editor, images, and accessibility. The default theme does not require the plugin.

## Image interaction

Desktop Obsidian 1.13.4 testing covered Live Preview image selection, copy/cut/delete,
grow/shrink/reset, Enter/Tab flows, zoom/lightbox, action buttons, resize, nested images, pop-outs,
and Vim image commands. Mobile image layout was checked in the official desktop mobile emulator.
Physical mobile gestures remain untested.

## Bases, Canvas, and Graph

Bases Table/Cards, Canvas nodes/groups/controls, and Graph node roles were tested on macOS desktop
Obsidian 1.13.4. The theme uses official variables for these surfaces and avoids renderer-internal
selectors.

## Accessibility

- Configured WCAG contrast pairs pass.
- Keyboard focus is visible in light, dark, image-selected, and forced-colors emulation paths.
- `prefers-reduced-motion`, `prefers-contrast: more`, and `forced-colors` rules are present.
- Real Windows High Contrast and assistive-technology sessions remain release prerequisites.

## Tested platform

- Obsidian Desktop `1.13.4`
- Installer `1.13.4`
- Electron `43.1.1`
- macOS 26.5, Apple silicon
- Desktop mobile emulator and controlled phone/tablet viewport classes
- Style Settings `1.0.9` in an ignored local test Vault

## Not yet physically tested

- iPhone / iPad
- Android phone / tablet
- Real mobile virtual keyboard, gestures, safe areas, and touch navigation
- Windows and Linux desktop chrome
- Real Windows High Contrast
- Screen-reader sessions

## Known limits

- This is a release candidate for public testing, not a complete compatibility guarantee.
- Third-party plugin compatibility is not broadly covered.
- The release package contains only `manifest.json` and `theme.css`; screenshots are repository
  presentation assets.
- The project is independent and unofficial. It does not include official artwork, logos, posters,
  screenshots, characters, or reference-image crops.
